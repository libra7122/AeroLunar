## 🌌 About the project

**AeroLunar** is a browser-based NASA-inspired space application that brings together interactive exploration and engineering education. The project began as an experiment in building a small game with Google AI Studio and is being developed and shared through GitHub.

## ✨ Project modules

The source code includes components for:

- **Space exploration** — an interactive game canvas and space-themed activities.
- **NASA machine explorer** — a section for discovering NASA-related machines and engineering concepts.
- **C++ code workbench** — an educational area featuring C++ source material.
- **Engineering quiz** — a quiz component for learning and review.
- **Audio utilities** — sound-related functionality within the app.

> Feature availability and behavior may evolve as the project develops.

## 💻 Run locally

You will need a recent version of **Node.js** and **npm**.

```bash
git clone https://github.com/libra7122/AeroLunar.git
cd AeroLunar
npm install
npm run dev
```

Open the local URL displayed by Vite in your terminal (the project is configured to use port `3000`).

To produce the static website build:

```bash
npm run build
```

The generated frontend assets are placed in `dist/`.

## 🌐 Deployment

The frontend is configured for deployment through **GitHub Pages** using **GitHub Actions**.

**Expected project URL:** https://libra7122.github.io/AeroLunar/

> If the site is unavailable, check the repository's **Actions** and **Settings → Pages** sections. GitHub Pages hosts static files, not a Node.js/Express backend. Any server-side functionality or private API credentials must be hosted and managed separately.
